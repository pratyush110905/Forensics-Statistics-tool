INTRODUCTION

My goal is to create a Forensics Statistics tool which can create simple outputs in terms of reports.
The tool is focused on analyzing money laundering/fraud cases data (bank statements), this type of data is usually enormous and hard for forensics scientists to read and understand.
I am using concepts of AI/ML and RAG based AI to achieve the desired results.

EXPECTED OUTCOME

The final output generated by the tool should contain all the relevant data regarding parameters like all the grey accounts in between the initial and final account; date, time, location, transaction ID, transaction type, amount, etc; shell companies; tax haven countries; reported by which authority; etc in a simple readable language.
